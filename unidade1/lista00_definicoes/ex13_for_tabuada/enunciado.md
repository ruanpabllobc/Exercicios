# Exercício 13 — Tabuada (for) — nível fácil

## Enunciado

Escreva um programa em Java que leia um número inteiro `n` e exiba a
**tabuada** desse número, de `n x 1` até `n x 10`, uma multiplicação por
linha. Use uma estrutura de repetição `for`.

## Pedido

> Utilizando `Scanner`, leia um `int n`. Com um laço
> `for (int i = 1; i <= 10; i++)`, exiba dez linhas no formato
> `"n x i = resultado"`, onde `resultado` é `n * i`.
>
> Identifique as três partes do `for`: a **inicialização** (`int i = 1`),
> executada uma única vez; a **condição** (`i <= 10`), testada antes de cada
> volta; e o **incremento** (`i++`), executado ao fim de cada volta.

## Exemplo de execução

```
Numero para a tabuada: 7
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63
7 x 10 = 70
```
