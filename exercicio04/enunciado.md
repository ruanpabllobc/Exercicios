# Exercício 04 — Cálculo de Média com Operador Ternário

## Enunciado

Escreva um programa em Java que leia duas notas de um aluno (números
decimais), calcule a média aritmética entre elas e informe se o aluno foi
**Aprovado** ou **Reprovado**. A decisão sobre a situação do aluno deve ser
feita obrigatoriamente utilizando o **operador ternário** (`condicao ? valorSeVerdadeiro : valorSeFalso`).

Considere que o aluno é aprovado quando a média for maior ou igual a 6.

## Pedido

> Utilizando `Scanner`, leia duas notas (`double`) chamadas `n1` e `n2`.
> Calcule a média `(n1 + n2) / 2`. Usando **apenas o operador ternário**
> (sem `if/else`), defina uma `String resultado` com o valor `"Aprovado"`
> caso `media >= 6`, ou `"Reprovado"` caso contrário. Ao final, exiba a
> média calculada e a situação do aluno.

## Exemplo de execução

```
Nota 1: 7
Nota 2: 8
Media: 7.5
Situacao: Aprovado
```
