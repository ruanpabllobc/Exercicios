# Exercício 02 — Entrada de Dados com Scanner

## Enunciado

Escreva um programa em Java que leia dados fornecidos pelo usuário através do
teclado, utilizando a classe `Scanner`. O programa deve ler três informações
de tipos diferentes: um número inteiro, uma cadeia de caracteres e um número
decimal. Ao final, deve exibir uma mensagem de saudação personalizada
utilizando os dados lidos.

## Pedido

> Utilizando a classe `Scanner`, crie um programa que:
>
> 1. Solicite e leia a **idade** do usuário (número inteiro);
> 2. Solicite e leia o **nome** do usuário (texto/String);
> 3. Solicite e leia a **altura** do usuário (número decimal);
> 4. Exiba uma mensagem no formato:
>    `"Ola, <nome>! Voce tem <idade> anos e <altura>m de altura."`
>
> Atenção: ao ler um `int` com `nextInt()` e, na sequência, precisar ler uma
> linha inteira com `nextLine()`, lembre-se de consumir a quebra de linha
> pendente antes de ler o texto.

## Exemplo de execução

```
Digite sua idade: 20
Digite seu nome: Ruan
Digite sua altura: 1.75
Ola, Ruan! Voce tem 20 anos e 1.75m de altura.
```
