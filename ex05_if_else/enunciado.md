# Exercício 05 — Cálculo de Média com if/else

## Enunciado

Escreva um programa em Java que leia duas notas de um aluno (números
decimais), calcule a média aritmética entre elas e informe se o aluno foi
**Aprovado** ou **Reprovado**. Desta vez, a decisão deve ser feita utilizando
uma estrutura condicional **if/else**, em vez do operador ternário usado no
exercício anterior — refazendo a mesma lógica do Exercício 04 de outra forma.

Considere que o aluno é aprovado quando a média for maior ou igual a 6.

## Pedido

> Utilizando `Scanner`, leia duas notas (`double`) chamadas `n1` e `n2`.
> Calcule a média `(n1 + n2) / 2` e exiba o valor calculado. Em seguida,
> utilizando uma estrutura `if/else` (não use operador ternário), exiba
> `"Situacao: Aprovado"` caso a média seja maior ou igual a 6, ou
> `"Situacao: Reprovado"` caso contrário.
>
> Dica: prefira `if/else` a operador ternário quando a ação a ser tomada em
> cada caso exigir mais de uma linha de código.

## Exemplo de execução

```
Nota 1: 5
Nota 2: 4
Media: 4.5
Situacao: Reprovado
```
