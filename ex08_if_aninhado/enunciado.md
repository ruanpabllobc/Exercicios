# Exercício 08 — Maior de Três Números (if aninhado)

## Enunciado

Escreva um programa em Java que leia três números inteiros e informe qual
deles é o **maior**. Desta vez, a decisão deve ser feita com `if`
**aninhado** (um `if` dentro de outro): primeiro comparamos dois números e,
dependendo do resultado, comparamos o vencedor com o terceiro.

## Pedido

> Utilizando `Scanner`, leia três inteiros `a`, `b` e `c`. **Sem usar o
> operador `&&`**, determine o maior valor usando `if` aninhado:
>
> - se `a >= b`, então o maior está entre `a` e `c`;
> - caso contrário, o maior está entre `b` e `c`.
>
> Guarde o resultado numa variável `int maior` e exiba `"Maior: <maior>"`.
>
> Compare com o Exercício 07 (operador `&&`): lá combinamos as condições
> numa única expressão booleana; aqui a decisão é quebrada em `if`
> encadeados, um dentro do outro.

## Exemplo de execução

```
a: 4
b: 9
c: 7
Maior: 9
```
