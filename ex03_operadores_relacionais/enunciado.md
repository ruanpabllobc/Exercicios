# Exercício 03 — Operadores Relacionais e Lógicos

## Enunciado

Escreva um programa em Java que declare duas variáveis inteiras, `a` e `b`,
com valores à sua escolha. Utilizando essas variáveis, aplique todos os
operadores relacionais disponíveis na linguagem e exiba o resultado
(verdadeiro ou falso) de cada comparação. Em seguida, crie duas expressões
booleanas e combine-as utilizando os operadores lógicos `&&` (E), `||` (OU)
e `!` (negação), exibindo o resultado de cada combinação.

## Pedido

> Declare `int a = 5;` e `int b = 3;`. A partir delas:
>
> 1. Exiba o resultado das comparações `a == b`, `a != b`, `a > b`, `a < b`,
>    `a >= b` e `a <= b`;
> 2. Crie duas variáveis booleanas, `cond1` (por exemplo, `a > b`) e `cond2`
>    (por exemplo, `b > 10`);
> 3. Exiba o resultado de `cond1 && cond2`, `cond1 || cond2` e `!cond1`,
>    explicando (em comentário ou na saída) por que cada operador lógico
>    produziu aquele resultado.

## Saída esperada

```
a == b: false
a != b: true
a > b : true
a < b : false
a >= b: true
a <= b: false
---
cond1 && cond2: false
cond1 || cond2: true
!cond1        : false
```
